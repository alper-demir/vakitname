# Vakit gizlilik sayfası

Bu klasör, Google Play gizlilik politikası alanı için JavaScript gerektirmeyen statik HTML sayfasıdır.

## Netlify'a yükleme

1. Yayımdan önce `index.html` içindeki geliştirici adı ve e-posta adresini Play geliştirici profiliyle doğrulayın.
2. Netlify Drop ekranına bu `privacy-site` klasörünü sürükleyin veya yeni bir statik site olarak bağlayın.
3. Açılan HTTPS adresini gizli pencerede, oturum açmadan ve JavaScript kapalıyken kontrol edin.
4. URL'yi Play Console gizlilik politikası alanına ve uygulamadaki Hakkında ekranına ekleyin.

PDF dosyasını Play Console gizlilik URL'si olarak kullanmayın; Google Play HTML sayfası ister.
